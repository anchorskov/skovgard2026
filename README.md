## Development Scripts

### scripts/devStart.sh
Starts both Hugo and Wrangler on localhost for local testing and development. This script initializes the Hugo static site generator and the Wrangler CLI for Cloudflare Workers development, allowing you to test the full application stack locally.

### scripts/stop.sh
Stops both Hugo and Wrangler processes that were started by devStart.sh. Use this script to cleanly shut down the local development environment.
