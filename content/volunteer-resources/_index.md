## Code of conduct
- Be respectful. No insults. No dehumanizing language.  
- Share facts. If unsure, pause and verify.  
- Represent the campaign with integrity.  
- Protect privacy. Never post private info from voters.

---

## Privacy
- Public files stay here.  
- Any lists with PII live off-site and behind authentication.  
- Volunteer data is never stored in the repo.
